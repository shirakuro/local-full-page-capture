# Local Full Page Capture

Chromeで現在のページ全体を1枚のPNGとして保存する、自分用のローカル拡張機能です。

## Chromeへの読み込み手順

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. このフォルダを選びます。

```text
C:\Users\tomoh\Documents\Codex\blog-sns-sai\chrome-full-page-capture
```

## 使い方

1. 撮影したいWebページを開きます。
2. Chrome右上の拡張機能アイコンから `Local Full Page Capture` を押します。
3. ページが自動でスクロールされます。
4. 保存ダイアログが出たらPNGを保存します。

保存先の初期フォルダは `full-page-captures` です。

ローカルのHTMLファイル、つまり `file://` で始まるページを撮る場合は、Chromeの拡張機能詳細画面で「ファイルのURLへのアクセスを許可する」をオンにしてください。

## ファイル名の設定

Chromeの拡張機能画面で `Local Full Page Capture` の「詳細」を開き、「拡張機能のオプション」から保存ファイル名を設定できます。

設定できる項目は次の通りです。

- 名前に使う情報: ページタイトル、URL、ページタイトル + URL
- 保存フォルダ名
- 連番の有無、次の番号、桁数
- 日時の有無

設定はこのPCのChrome内に保存されます。外部サーバーへ送信されません。

## 現時点の制限

- `chrome://settings` やChrome Web Storeなど、Chrome内部ページでは動きません。
- 固定ヘッダーがあるページでは、ヘッダーが複数回写ることがあります。
- 無限スクロールや遅延読み込みが強いページでは、完全に揃わないことがあります。
- とても長いページは、ChromeのCanvasサイズやメモリ制限で失敗する場合があります。

## 権限について

- `activeTab`: ボタンを押した現在のタブだけを一時的に操作・撮影します。
- `scripting`: 現在のページをスクロールするための短い処理を一時的に実行します。
- `downloads`: 作成したPNGを保存します。
- `storage`: ファイル名の設定と次の連番をこのPC内に保存します。

画像処理はブラウザ内だけで行い、外部サーバーには送信しません。
